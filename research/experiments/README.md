# Research Experiments

This directory contains the historical scientific record of the NeuroAegis project.

## Phase Mapping
| Historical Phase | Target Directory | Description |
|---|---|---|
| Phase 1 | `dataset_annotation_pipeline` | Initial dataset downloading and annotation parsing |
| Phase 2 | `windowing_labeling` | Window construction and labeling rules |
| Phase 3 | `cnn_baseline` | 1D CNN baseline model |
| Phase 4A | `gnn` | Spatial GNN representation learning |
| Phase 4B | `model_c` | Final Model C (CNN + GNN + Causal GRU) |
| Phase 5 | `xai` | Explainability with Integrated Gradients |
| Phase 6 | `siena` | Siena cross-domain adaptation |
| Phase 7 | `ablation` | Ablation studies |
| Phase 9 | `temporal_post_processing` | Temporal smoothing rules exploration |
