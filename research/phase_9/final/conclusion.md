# Conclusion

In this work, we developed and audited NeuroAegis, a lightweight spatio-temporal deep learning framework for patient-independent epileptic seizure detection in continuous scalp EEG. By coupling a 1D convolutional feature extractor with a validation-frozen spatial graph convolutional network (GNN, $\theta=0.30$, 23 nodes, 40 edges) and a causal unidirectional gated recurrent unit (GRU, sequence length $L=8$, 22.5 s context), the complete 91,858-parameter model achieved 95.45% event sensitivity on the strictly held-out CHB-MIT test cohort (21 of 22 seizures detected across 152.82 continuous recording hours).

A key methodological insight from our ablation experiments is the functional interplay between spatial and temporal modeling. While spatial graph convolutions alone dramatically suppress false alarms by 89.7% through global spatial filtering, they induce severe event sensitivity collapse (27.27%) due to over-smoothing of focal electrographic discharges. Integrating causal recurrent temporal memory restores temporal continuity, recovering event sensitivity to 95.45% while further reducing false alarms to 62.66 FA/24h (-96.8% relative to the 1D-CNN baseline). The final frozen model achieved 0.98970 AUROC, 0.80681 AUPRC, and a median detection delay of 9.0 seconds.

External evaluation on a benchmark subset of the Siena Scalp EEG repository (2 patients, 4 recordings, 4 events, 2.46 hours) provided preliminary evidence of cross-domain generalization, achieving 100% zero-shot event sensitivity and 0.0 false alarms per 24 hours. Furthermore, a non-invasive post-hoc calibration protocol improved target F1 score on unseen patient PN12 from 0.3043 to 0.3750 (+23.2% relative gain) without parameter fine-tuning. Quantitative explainability using Integrated Gradients revealed salient attributions concentrated in temporal-parietal channels (`T7-P7`, `P3-O1`), with explanation faithfulness verified via monotonic perturbation deletion curves ($0.8093 \to 0.2011$).

Despite these promising retrospective results, several methodological boundaries must be acknowledged: the CHB-MIT test cohort comprised four pediatric patients, exactly one focal seizure (`chb01_15`) was missed, the Siena evaluation was restricted to a two-patient benchmark subset, and clinician-in-the-loop validation of attribution maps was not conducted. Prospective, multi-center clinical trials on unsegmented continuous EEG streams remain essential before this system can be translated into real-world inpatient or ambulatory neuro-monitoring workflows.
